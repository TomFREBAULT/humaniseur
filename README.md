# humaniseur

Skill Claude Code qui réécrit un texte français « qui sonne IA » pour qu'il sonne humain, sans changer ce qu'il dit.

Adaptation française de [blader/humanizer](https://github.com/blader/humanizer) v4.0.0 (MIT) : mêmes 26 motifs structurels, exemples réécrits en français, listes de mots fétiches francophones, calques de l'anglais (§10) et typographie française (§21).

## Installation

```bash
git clone https://github.com/TomFREBAULT/humaniseur.git ~/.claude/skills/humaniseur
```

Puis, dans une nouvelle session : `/humaniseur` suivi du texte, ou simplement « rends ce texte moins IA ».
